# SCM_Asim
This repository is created for the SWE 442 assignment to demonstrate software configuration management, version control workflows, branching, and change tracking using GitHub.
## Change Control Process
All changes in this repository follow a structured change control workflow. Proposed updates and documentation improvements are first tracked using GitHub Issues (issue #2 "Clarify Project Documentation"). Feature work and file additions are developed in isolation on a dedicated branch (`docs-update`) rather than directly on `main`. Once changes are tested and committed using standardized commit messages, a Pull Request (#1) is opened to review the modifications before merging them back into the `main` branch.
